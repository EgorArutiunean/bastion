# Bastion BJJ

React/Vite сайт секции Brazilian Jiu-Jitsu и грэпплинга в Бендерах и Тирасполе.

## Команды

```bash
npm run dev
npm run build
npm run deploy
```

`vite.config.ts` использует `base: '/bastion/'`, поэтому сборка готова для GitHub Pages репозитория `EgorArutiunean/bastion`.

## Материалы

Реальные материалы старой версии сайта перенесены в `public/old-site`: hero-фото, логотип, иконки групп, фото клуба и фон с поясами.
